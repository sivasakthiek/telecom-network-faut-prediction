# Mission: Telecom Fault Prediction & Hybrid RAG Architecture

## Why
To confidently maintain, debug, and expand the NOC command center's query-routing, hybrid RAG, and SHAP-based What-If prediction-progression systems. Acquiring this skill allows the user to easily update the underlying intelligence, troubleshoot classification mismatches, and extend dashboard capabilities.

## Success looks like
- Explain the precise step-by-step pipeline from user query input to final LLM response.
- Describe how SHAP values are extracted from the XGBoost model and transformed into deterministic What-If progressions.
- Diagnose and fix query routing classifications inside the LLM service.
- Understand the offline RAG system structure (data loading, chunking, FAISS index, and direct lookup).

## Constraints
- Focus on practical, codebase-grounded explanations directly citing repository files.
- Keep lessons brief, self-contained, and interactive (desirable difficulty).

## Out of scope
- Deep-dive training of new XGBoost model weights.
- Advanced Streamlit UI layout redesign from scratch.
